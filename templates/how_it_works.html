1. What Flask Does & Used Libraries

Flask is a micro web framework written in Python. It is called "micro" because it does not require particular tools or libraries, keeping the core lightweight while remaining extremely flexible. In this project, Flask behaves as the central web server that listens for traffic from your browser, decides how to handle that traffic, and sends back the correct response (like an HTML page or a redirect command).

Here are the standard libraries used in app.py and what they accomplish:

  • flask (Flask, render_template, request, etc.): Used to manage our server, compile HTML views, receive forms, and issue user alert overlays.
  • json: Used to parse files written in JSON format into Python lists/dictionaries, and encode them back to save updates.
  • os: Interacts with the computer's directory paths safely so Flask can locate file resources regardless of the operating system (Windows, Mac, or Linux).
  • uuid: Generates "Universally Unique Identifiers" (long, random strings of characters) so every goal, note, resource, and log has a guaranteed unique id.
  • datetime: Used to stamp our sticky notes with the current calendar date and time when they are posted.

2. What are Routes?

A Route in web development maps a specific URL (like /dashboard or /goals) to a specific Python function in our code. We define these routes in Flask using decorators starting with @app.route().

When you type a URL or click a link, the browser sends an HTTP request. Flask intercepts it and executes the function associated with that route path. For example, here is our dashboard routing logic:

@app.route('/dashboard') def dashboard(): # 1. Load data from JSON database files goals = load_data('goals.json') notes = load_data('notes.json') # 2. Package stats and recent entries stats = { 'total_goals': len(goals) } recent_notes = notes[-3:] # Get latest notes # 3. Render and return the HTML layout return render_template('dashboard.html', stats=stats, recent_notes=recent_notes)

3. What are Templates?

Writing static HTML is limiting because data changes constantly. A Template is an HTML file containing placeholders and logical syntax. Flask uses a template rendering engine called Jinja2.

In this project, templates allow us to perform dynamic layout computations directly in HTML, like looping through a list of sticky notes or conditionally drawing colored status badges:

<!-- Jinja2 Syntax Example --> {% raw %}{% if goals %} {% for goal in goals %} <div class="item-card"> <h3>{{ goal.title }}</h3> <span>Category: {{ goal.category }}</span> </div> {% endfor %} {% else %} <p>No active goals found!</p> {% endif %}{% endraw %}

We also use Template Inheritance ({% raw %}{% extends 'base.html' %}{% endraw %}). This allows us to write the navigation menu, logo, footer, and styling links only once in base.html, and inherit them across all other views.

4. What a JSON Database Means & GPA Math

Traditional web applications use relational databases (like SQLite, MySQL, or PostgreSQL) which require writing SQL queries. To keep this project beginner-friendly and lightweight, we use a JSON file database.

JSON stands for JavaScript Object Notation. It is a text file layout that represents data in a structured key-value format. The text format maps directly to Python's built-in lists and dictionaries. When the app starts, we open the text files using Python's json.load() function, modify the lists, and save the updated contents back to disk using json.dump().

For example, here is how a marks entry is formatted in data/marks.json. Notice how the backend automatically computes the total score and translates it into a letter grade and numeric gp (Grade Point):

# Standard academic record stored in data/marks.json: { "id": "a49bb2d3-1349-411a-8bb7-e54bf83141f2", "course_name": "Database Management Systems", "semester": 3, "credits": 4, "mtt1": 18.5, "mtt2": 17.0, "ica": 19.0, "term_end": 35.5, "total": 90.0, "grade": "O", "gp": 10 }

The GPA Mathematics:

  • Total Marks: Sum of MTT 1 (0-10) + MTT 2 (0-10) + ICA (0-30) + Term End scaled to 50 (TEE * 0.5) = Total (0-100).
  • Grade Point (GP): Calculated on a 10-point scale where scores ≥ 90 earn 10 GP (O), ≥ 80 earn 9 GP (A+), ≥ 70 earn 8 GP (A), and so forth. Scores < 40 earn 0 GP (F).
  • Semester SGPA: Calculated as: Sum(Course GP * Course Credits) / Sum(Course Credits) for that semester's courses.
  • Cumulative CGPA: The credit-weighted average of all courses across all recorded semesters.

5. How Form Data is Processed & Saved

When you click a submit button on any form (like adding a resource or logging hours), the browser packs up the inputs and sends them to the Flask server via an HTTP POST request.

The backend performs the following steps to process the form submission:

  • Route Interception: The route configuration permits both GET (viewing) and POST (saving) methods.
  • Form Reading: Flask extracts the input text utilizing the request.form.get('input_name') property.
  • UUID & Stamping: Python attaches a newly generated uuid.uuid4() string identifier and handles status defaults.
  • File Append: We load the current list from the JSON file, append the new item dictionary to it, and write the updated list back to the filesystem.
  • Session Flash Notification: A message is saved to the session indicating successful creation, and the browser is redirected to refresh the list views.
