1. Request Lifecycle

Every time you request a page or submit a form, a request-response cycle occurs between the browser and the Python Flask backend.

01
Browser Request: You request a page (e.g. visiting /dashboard). The browser sends an HTTP request.
02
Flask Routing: Flask receives the request and matches the path with a route decorator, e.g. @app.route('/dashboard').
03
Logic Execution: Flask runs the view function, checks session cookies, loads data from local JSON databases, and calculates metrics.
04
Jinja Rendering: Flask compiles the templates (e.g. dashboard.html) using Jinja2, replacing tags with dynamic variables to build raw HTML.
05
HTTP Response: Flask returns the compiled HTML to the browser, which renders the user interface.

2. Standard Libraries

This project uses standard Python modules for a clean, self-contained implementation:

  • flask: Handles routing, session cookies, flash alerts, and HTML template rendering.
  • json: Reads and writes database files on disk.
  • os: Manages cross-platform file system paths.
  • uuid: Generates unique identifiers for goals, notes, and marks.
  • datetime: Timestamps sticky notes and evaluates deadlines.

3. Security & Cookies

Password Hashing

We do not store passwords in plain text. When a student registers, we hash their password using generate_password_hash, converting it into a cryptographic string that cannot be decrypted. Upon login, we verify the hash match using check_password_hash.

Session Cookies

To identify users across HTTP requests, the backend sets session variables (e.g., session['user_id']). Flask signs the session cookie cryptographically using the secret_key to prevent browser tampering.

4. Database & GPA Math

Instead of SQL databases, CampusDeck stores data inside simple, structured JSON files in the data/ folder. Dynamic metrics are calculated directly by the backend:

  • Exam Weighting: Term-End Exam (TEE) marks are scaled down to 50% weight (weighted score = term_end * 0.5).
  • Total Marks: Total score = MTT 1 (max 10) + MTT 2 (max 10) + ICA (max 30) + TEE Weighted (max 50).
  • SGPA Calculation: Calculated as a credit-weighted average:
    SGPA = Sum(GP * Credits) / Sum(Credits)
  • CGPA: Evaluated as the cumulative credit-weighted average GPA across all logged semesters.

5. Form Processing

How inputs are saved without database corruption:

  1. Submit: Forms send field data securely to Flask using a POST request.
  2. Read: Flask views access fields via request.form.get().
  3. Write: The list is updated in memory and committed to local storage via json.dump().
  4. Redirect: Flask issues a redirect status to prevent form resubmission on page refreshes.

6. Python Concepts

Dictionaries

Data objects are represented as dictionaries for simple JSON storage mapping:

new_note = { 'id': 'a82bc...', 'title': 'Calculus Formulas', 'content': 'Study Big-O and derivative proofs', 'color': 'yellow' }

List Comprehensions

Used to cleanly filter user database records in memory:

user_notes = [note for note in all_notes if note.get('user_id') == session.get('user_id')]
